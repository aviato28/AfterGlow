# M4.2 — Quick panel: no popup at boot, never silently dead

Owner's 0.7.1 test: the panel works in YouTube and Penumbra+, but (1) every time the TV turns on Android shows "Allow Afterglow to access all
device logs? Allow one-time access / Don't allow", and (2) the panel sometimes doesn't open. Read `CLAUDE.md`, `docs/specs/M4-quick-panel.md`, then only
`keys/*.kt`, `panel/*.kt`, `takeover/AdbShell.kt` and their tests.

## 1. No log-access popup (cause: Android 13+ asks the user every time an app reads logs with READ_LOGS; there is no "always")
- Use the **Adb** reader only (shell user, no popup). Remove the Local reader and the `READ_LOGS` grant from switch-on. Switching on (and, once, on upgrade
  when the feature is already on) runs `pm revoke com.nbansal.afterglow android.permission.READ_LOGS` so the popup can never come back. Keep `RevokeLogs` in
  the whitelist; drop `GrantLogs`. Unit-test: source choice is always Adb.

## 2. Never silently dead
- Heartbeat: while the screen is on, every 30 s the service logs one line with tag `WindowManager` and text `afterglow-heartbeat` (an app may use any tag; the
  reader's `WindowManager:D` filter then sees it). If the reader has not seen a heartbeat for 75 s, kill and restart it. Restart on `ACTION_SCREEN_ON`
  and on `ACTION_USER_PRESENT`/boot too. Never faster than every 5 s.
- Service: `START_STICKY`; re-start it from `HomeActivity.onResume` if the switch is on and it isn't running.
- Panel open failures: wrap `addView` in try/catch, record the error. Known Android limit: overlays are hidden on Android Settings screens and system
  dialogs (by design); say so in one line on the Quick panel page.
- Diagnostics: source, reader up since, last heartbeat age, Settings presses seen, panels shown, last panel error, last reader error.
